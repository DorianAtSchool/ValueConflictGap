# Value-Conflict Data

This directory contains the static ConflictScope-derived inputs used by the
paper's value-conflict experiments:

- VCA: value-conflict agreement-to-action
- VCA-b: VCA with explicit trade-off prompting
- VCP: value-conflict preference-to-action

Vendored files:

```text
personalprotective/claude-3-5-sonnet-latest.csv
personalprotective/prompts.json
value_sets/personalprotective.json
```

```text

conflictscope/data/personalprotective/prompts.json

```
