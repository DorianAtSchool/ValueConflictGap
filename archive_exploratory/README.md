# Exploratory Archive

This folder is reserved for code paths that are not part of the clean paper
experiment interface, such as multi-turn conversations, open-ended judging,
stance sweeps, and other exploratory variants.

Nothing has been deleted from `pipeline/` yet. The current refactor introduces a
clean, paper-facing interface in `src/experiments/` and `scripts/` first, so the
legacy code can be inspected and moved here in smaller, reviewable steps.
